# canvas-py

Typed Canvas REST client, application-shaped navigation, document extraction,
and student actions. This package is maintained inside Canvas Connector.

Use the repository root README for installation and supported client setup.
Explicit `CanvasConfig` values select credentials; private environment files
are supported for personal use. The hosted adapter supplies credentials from
an authenticated OAuth grant and applies its guarded network transport.
