The connector supports the Canvas student API. Quizzes, proctoring, and some external learning tools still need their own interface.

Can I use it without a hosted server?

Yes. Codex, Claude Code, and compatible desktop clients can launch the connector locally. Install the source with Python 3.12, keep your personal Canvas URL and token in a private file, then register the canvas-connector stdio command. Cloud-based ChatGPT and Claude connectors need a reachable HTTPS server.

What happens to my school account?

For hosted connections, you sign in through your school’s Canvas. The server stores encrypted credentials to retrieve your course information. Choose a server operator you trust. A personal local connection keeps the connector on your computer.

What about Google Docs and Microsoft files?

Your assistant can use the relevant connected app. If the file is limited to your school, that app needs access through the right school account. The connector explains when access is missing.

Why isn’t there a one-click install?

Custom connectors use each assistant’s supported setup flow. A direct app-directory install link becomes available only after a listing is published. The steps above work with your own hosted endpoint.
