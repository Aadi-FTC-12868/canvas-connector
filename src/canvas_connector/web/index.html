On your computer

Personal setup for ChatGPT

Connect your own Canvas account through OpenAI Secure MCP Tunnel. This setup supports macOS and Linux; your computer must stay awake with the runner open.

  1. Check that you can create and use a tunnel in OpenAI Platform and add a custom MCP server in ChatGPT Plugins. Keep access to this personal tunnel limited to you.
  2. Install Python 3, UV and the official tunnel client. Download and extract the source package below.
  3. Open a terminal in the extracted folder containing scripts/ and run the setup command. It guides private credential entry and starts your connection; writes start off.
  4. In ChatGPT Plugins, add a custom MCP server, choose Tunnel and select your tunnel. Use No authentication for this personal setup, install the plugin, then ask for your Canvas connection status to verify the account.
Download personal ChatGPT setup

Enter tokens only into the runner’s private terminal prompts, never a chat. Anyone allowed to use this tunnel can access the configured Canvas account. This is a personal connection; it does not start a public Canvas service. OpenAI account and workspace access are separate from this free connector.

On your computer

Personal setup for Claude Desktop

Download the extension for your own Canvas account. Claude keeps the token in its secure credential storage. Writes start off.

Download for Claude Desktop
  1. In Claude Desktop, open Settings → Desktop app → Extensions, then Advanced settings → Install Extension.
  2. Select the downloaded .mcpb file and follow Claude’s installation prompts.
  3. Enter your school’s Canvas address and your own token in Claude’s settings. Ask for your Canvas dashboard to check the account.

Personal local use only. Initial setup downloads Python dependencies. This download does not connect Claude’s web or mobile app.

The connector supports the Canvas student API. Quizzes, proctoring, and some external learning tools still need their own interface.

Can I use it without a hosted server?

Yes. Choose ChatGPT for personal Secure MCP Tunnel setup, Claude for the personal desktop extension, or Codex or Claude Code for the personal plugin from GitHub. A downloadable ZIP is also available as a fallback. You can also install the Python source. Local use requires your own Canvas account credentials; your school may restrict API access.

What happens to my school account?

A local connection runs on your computer using your own Canvas URL and token. The planned Built by Aadi hosted beta uses your Built by Aadi login and stores your Canvas connection in our Cloudflare infrastructure. The token is sent to your Canvas server to authenticate requests, never to your AI assistant. The assistant does receive the Canvas information you ask it to retrieve. Hosted setup shows a beta notice before you enter credentials.

What about Google Docs and Microsoft files?

Your assistant can use the relevant connected app. If the file is limited to your school, that app needs access through the right school account. The connector explains when access is missing.

Which setup works on the web and mobile?

ChatGPT can use a personal Secure MCP Tunnel while your computer is running, subject to account and workspace access. Hosted ChatGPT and Claude connections need a reachable HTTPS service and the operator’s supported sign-in flow. A Built by Aadi account alone does not grant Canvas access. Desktop downloads run locally. Each assistant handles installation and permissions; a download does not complete account setup.
